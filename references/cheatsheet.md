# 决策规则速查 — 《普通人赚钱的十二层阶梯》

| 能力 | 一句话规则 |
|---|---|
| 真实时薪与时间资产审计 | 先扣除工作相关成本并记录一周时间，再决定哪些时间值得回收和投入。 |
| 十二层收入结构诊断与跃迁计划 | 识别收入主要来自时间、技能、产品、信息、流量、系统或资源杠杆，再只选一个可验证的下一步。 |
| 技能方向与最小服务验证 | 用喜欢/擅长四象限筛方向，再用付费需求、最小交付和现有工具三问做低成本验证。 |
| 技能服务产品化与价值报价 | 把服务边界、交付标准、修改次数和验收结果写成可报价、可复用的服务包。 |
| 目标倒推的项目制学习 | 先定义可交付作品，再倒推子技能、短教程、练习和反馈循环。 |
| MVP、预售与低成本需求验证 | 用最小交付、预售、代发或样品先换真实订单和反馈，再决定迭代、扩大或止损。 |
| 轻量化店铺、库存与现金流闸门 | 先算成本与保本点，用小规模、低库存的店铺跑通展示—成交—交付，再升级。 |
| 复盘、萃取与可复用资产 | 复盘结果和失败，把稳定做法写成SOP/模板，再用下一次交付验证。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
